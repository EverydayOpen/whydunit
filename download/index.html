Try the beta

Free · macOS 15 or later · Apple silicon and Intel

  1. Open the disk image

    Download the beta's DMG from GitHub and double-click it.

  2. Drag to Applications

    Drag Whydunit onto the Applications folder.

  3. Allow it once

    The beta isn't notarized yet, so macOS blocks it the first time. Open it, then click Open Anyway in System Settings › Privacy & Security.
