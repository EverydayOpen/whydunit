# Competitor and landscape teardown for need (2): "Will my work survive a macOS upgrade?"

Research date: 2026-09-27. macOS 27 Golden Gate shipped on 2026-09-14. Confidence labels: **verified** means I read it in a primary or near-primary source. **reported** means it comes from a secondary source (press or forum) that I could not check against a primary one. **unverified** means I could not confirm it.

---

## 0. TL;DR

1. **Rosetta timeline (verified from Apple).** macOS 27 is the last release where Rosetta works as a general tool. Starting with macOS 28 (expected fall 2027), Rosetta remains only for "certain older, unmaintained games that rely on Intel-based frameworks" ([Apple Support 102527](https://support.apple.com/en-us/102527), [Apple Developer news, 1 Sep 2026](https://developer.apple.com/news/?id=w5ngl9k2)). The real deadline for Intel-only software is the **macOS 28 upgrade**, not macOS 27.
2. **Scanning for Intel-only software is already a commodity, and Apple now does part of it for free.** macOS 27 lists Intel apps in Settings > General (About) > Intel-based apps > Details. It also flags them in Get Info and shows periodic launch warnings. Rosetta Check ($6.99, one-time) already scans apps, plug-ins, system extensions, login items, XPC helpers and CLI tools. It gives a readiness score, exports CSV/JSON and supports MDM. Go64 (free) and RoaringApps (free) cover the basics. **A new app that only inventories Intel binaries would lose.**
3. **Most macOS 27 breakage has nothing to do with Rosetta.** Native Instruments says its hardware and software are "not supported" on 27 even though NI products run natively. UA reports display issues. u-he, Air Music Tech, BFD and Moog say not supported. Premiere had crashes during the beta. VPN and network-extension problems appear on Reddit. Photoshop's Generator failed because the upgrade **removed Rosetta** and Generator bundles an x86_64 Node binary. A tool that only checks CPU architecture misses all of this. **The gap is "is each item in *my* setup certified for the target OS, and does *my* project still open, print, export and connect?"**
4. **A "test drive macOS 27 in a VM with your project files" feature is technically possible but a poor v1 for a solo developer on Windows.** Reasons: fragile installs across host and guest versions (Apple confirmed a `VZMacOSInstaller` incompatibility between macOS 26.x hosts and the macOS 27 IPSW), a limit of 2 macOS VMs, no USB audio interfaces or iPhones inside the VM, unreliable App Store sign-in, per-machine licence activations, tens of GB of disk, and above all **no way to test it in CI**: GitHub's arm64 macOS runners are M1 machines and "Nested-virtualization is not supported". The VM shell itself is already sold or given away: CleanRoom $9.99, UTM free/$9.99, VirtualBuddy free, Parallels from $99/yr.
5. **Recommended wedge:** an "upgrade rehearsal" app for non-technical and prosumer users. It would combine (a) a full inventory: architecture **plus vendor-certification status**; (b) a pre-upgrade baseline snapshot; (c) a checklist of the user's own workflows ("open these 3 projects, print a test page, connect the VPN, load the DAW session"); (d) a check that a backup and rollback path exist; and (e) an automatic post-upgrade re-scan that diffs against the baseline, catches problems like "Rosetta was removed" and "a plug-in disappeared", and suggests fixes. Sell it on a lifetime licence. Time the launch for the macOS 28 "Rosetta cliff" (WWDC June 2027 through fall 2027).

### What macOS 27 does natively (the free built-in competitor)
- **Settings list:** "Settings > General now lists Intel-based apps that will be incompatible with macOS 28.0. The list also identifies unused Intel-based software discovered on the system. The system might suggest a website where an Apple silicon native version can be found for a listed app. (175697313)". Source: macOS 27 release notes (verified). The path is reported as System Settings > General > About > Intel-based apps > Details ([MacRumors](https://www.macrumors.com/2026/06/12/macos-golden-gate-rosetta-support/), [Six Colors](https://sixcolors.com/post/2026/08/preparing-for-next-years-rosetta-2-demise/)).
- **Get Info:** "Intel-based applications that will no longer run in macOS 28.0 now display a treatment in Get Info. (169548657)" (verified).
- **Launch warnings:** macOS 27 warns that Intel apps "will not open in macOS 28" ([Der Flounder, 15 Sep 2026](https://derflounder.wordpress.com/2026/09/15/intel-apps-and-macos-golden-gate/)). This is reported.
- **Known blind spots:** plug-ins and loaders, per Apple's own notes. PaperCut says the list "only shows user-facing applications and does not include background agents like the Application Server or Print Provider" ([PaperCut KB](https://www.papercut.com/kb/Main/macos-rosetta-transition-end-of-life/)). The list also has no view of CLI tools, printer filters, launch daemons or nested helpers. Rosetta Check's blog exploits exactly these gaps ([rosettacheck.com/blog/macos-27-intel-app-list](https://rosettacheck.com/blog/macos-27-intel-app-list)).
- **Apple's underlying usage data:** `system_profiler -json SPLegacySoftwareDataType` returns legacy software that has actually launched. Jamf's extension attribute filters on `.has_native_version == "has_native_version_no"` or `.reason == "reason_x86_only"` and reads `.responsible_identity.identity_bundle_id` and `.identity_path` ([Jamf/talkingmoose gist](https://gist.github.com/talkingmoose/b3553675a613176b35c27b5c5028e0c2), updated 20 Sep 2026 "Added support for system_profiler data returned from Golden Gate"). This is verified from the code. **The format is undocumented and changed between 26 and 27, so parsing it is brittle.**

### 2e. MDM / B2B comparables

- **Jamf Pro**: no packaged "OS readiness" product was found. Admins use (1) a community extension attribute by Jamf's William Smith that combines `system_profiler -json SPLegacySoftwareDataType` with `mdfind 'kMDItemExecutableArchitectures == "x86_64" && kMDItemExecutableArchitectures != "arm64" && kMDItemContentType == "com.apple.application-bundle"'` and reports apps as "IN USE" or "NEVER USED" ([gist](https://gist.github.com/talkingmoose/b3553675a613176b35c27b5c5028e0c2)); (2) Blueprints to suppress the Rosetta pop-up (`allowRosettaUsageAwareness` = false); (3) Smart Groups; and (4) upgrade deferral through `enforcedSoftwareUpdateMajorOSDeferredInstallDelay` / `forceDelayedMajorSoftwareUpdates` (Restrictions) or the DDM `softwareupdate.settings` → `Deferrals.MajorPeriodInDays` ([apple/device-management](https://github.com/apple/device-management)). Pricing was not researched.
- **Iru (formerly Kandji)**: renamed in Oct 2025, with a Kandji migration deadline of 1 Dec 2026 (reported, from a search summary). The blog post "Apple OS 27 Is Here. Iru Is Ready." is dated 14 Sep 2026 ([iru.com blog](https://www.iru.com/blog/testing-prerelease-operating-systems-apple)). **I found no dedicated Intel-app readiness report** (unverified).
- **Mosyle**: **I found no dedicated Golden Gate / Rosetta readiness feature** (unverified).
- **Rosetta Check** also ships MDM managed settings, which makes it both a consumer and a light B2B competitor.
- B2B lesson: IT teams build readiness from inventory, usage, deferral and a pilot group. The pilot group is the enterprise version of the "test drive". Consumers have no pilot group, and that is the analogue a consumer app can offer.

## 3. 2026 macOS 27 app-compatibility complaints (evidence of pain)

- **Rosetta missing after the upgrade**, which silently breaks Intel helpers inside native apps (Photoshop Generator, printer utilities). Documented by Apple (163213094). Coverage in [Mac Observer](https://www.macobserver.com/news/macos-27-golden-gate-musicians-native-instruments-focusrite-say-wait/), [MacsOnly first-week problems](https://macsonly.com/article/2026/tip-macos-27-golden-gates-first-week-problems-and-fixes), a Hacker News comment ([HN 49732036](https://news.ycombinator.com/item?id=49732036)), and a Production Expert reader who "fixed it by accident when I opened an app that required Rosetta".
- **Audio plug-ins.** "Updated MAC OS to 27 Golden Gate and lost all of my audio VST plugins… spinning beach ball… Had to reinstall everything" ([Adobe Community](https://community.adobe.com/bug-reports-728/updated-mac-os-to-27-golden-gate-and-lost-all-of-my-audio-vst-plugins-even-the-apple-pre-installed-ones-when-i-tried-to-re-scani-go-the-spinning-beach-ball-of-death-had-to-reinstall-evrything-to-get-them-back-1642536)). NI, u-he, BFD, Moog and Air say not supported. Musicians are told to wait ([Mac Observer](https://www.macobserver.com/news/macos-27-golden-gate-musicians-native-instruments-focusrite-say-wait/)).
- **VPN / network extensions.** A Reddit thread titled "MacOS 27 killed all my VPN connections" (r/MacOS). Beta-era "Networking woes": uninstalling Cisco Secure Client cleared the issues, and disabling the Socket Filter extension let the VPN connect (r/MacOSBeta). Reddit could not be fetched, so this is reported from search snippets only. Cisco Secure Client lists macOS 27 support ([Cisco release notes](https://www.cisco.com/c/en/us/td/docs/security/vpn_client/anyconnect/Cisco-Secure-Client-5/release/notes/release-notes-cisco-secure-client-5-1.html), reported). MacHow2 tells readers to check for explicit Golden Gate support "rather than relying solely on the fact that the application launches".
- **Printers and scanners.** AirPrint keeps working, but vendor utilities and older filters can depend on Rosetta. ScanSnap Home is "under evaluation" ([MacHow2](https://machow2.com/macos-27-golden-gate-compatibility/)). Apple lists `~/Library/Printers/` among the places to check by hand (verified).
- **Adobe.** Not certified. Beta Premiere crashes. Generator needs Rosetta (verified).
- **Security/utility changes that break utilities:** "Apps can no longer access the local TCC database directly" ([Apple enterprise notes](https://support.apple.com/en-us/148830), verified via search excerpt). Blake Crosley also lists cross-team container reads being denied and a new `spctl` purge command ([blakecrosley.com](https://blakecrosley.com/blog/macos-27-golden-gate-release)), which is reported.
- **General first-week bugs** (Mission Control, Wi-Fi, disk growth of about 30 GB from AI assets according to Howard Oakley via MacsOnly) add to "should I upgrade at all?" anxiety ([TechRadar](https://www.techradar.com/computing/mac-os/never-have-i-experienced-such-a-windows-esque-bug-in-macos-mission-control-is-a-mess-in-macos-27-golden-gate-and-users-are-questioning-apples-testing)). All reported.
- **Consensus advice** in the press: wait for 27.1, and check every vendor ([MacHow2](https://machow2.com/macos-27-golden-gate-compatibility/)).

## 4. What a consumer app can realistically do before an upgrade

### 4a. Inventory (all feasible; every API below is verified in Apple docs unless marked)

| Target | How | Notes |
|---|---|---|
| App architecture | `Bundle(url:)?.executableArchitectures` → `[NSNumber]`, compared against `NSBundleExecutableArchitectureARM64` (macOS 11+) and `NSBundleExecutableArchitectureX86_64` | [Apple docs](https://developer.apple.com/documentation/foundation/bundle/executablearchitectures). Treat `arm64e` as native (Fleet's warning). |
| Fast system-wide app list | `NSMetadataQuery` on `kMDItemExecutableArchitectures` plus `kMDItemContentType == "com.apple.application-bundle"`. Or shell out to `system_profiler -json SPApplicationsDataType`, which has an `arch_kind` field ([Velociraptor artifact](https://github.com/velocidex/velociraptor-docs/blob/d88489acae3045e7386f37de4fbce0afde1c146e/content/artifact_references/pages/macos.system.packages.md)). | `arch_kind` values are unverified. Spotlight misses non-indexed volumes. |
| Running translated processes | `NSRunningApplication.executableArchitecture` (verified). osquery `processes.translated` | Covers only what is running now |
| Apple's "legacy in use" list | `system_profiler -json SPLegacySoftwareDataType` (keys `has_native_version`, `reason`, `responsible_identity.identity_bundle_id/identity_path`) | Undocumented. The format changed in 27. |
| Nested binaries | Walk `Contents/{MacOS,Frameworks,PlugIns,XPCServices,Helpers,Library/LoginItems,Library/LaunchServices,Library/SystemExtensions}` and read the Mach-O / fat header of each executable | This is Rosetta Check's key feature. Parse the headers yourself; `lipo -archs` is the CLI equivalent. |
| Audio plug-ins | Enumerate `/Library/Audio/Plug-Ins/{Components,VST,VST3,CLAP,HAL}`, the same folders under `~/Library/Audio/Plug-Ins/`, and AAX under `/Library/Application Support/Avid/Audio/Plug-Ins`. AU registry via `AVAudioUnitComponentManager` (macOS 10.10+). `auval -a` to list, `auval -v <type> <subtype> <manu>` to validate. | Apple names `~/Library/Audio/Plug-Ins/*`. The AAX path and `auval` flags are standard but were not re-verified here. |
| Printer drivers / PDEs / filters | `/Library/Printers/`, `~/Library/Printers/`, `/usr/libexec/cups/filter`, `lpstat -v` | Paths from Apple and PaperCut are verified. `lpstat` is standard CUPS. |
| Other loaders | `~/Library/ColorPickers`, `/Library/QuickLook`, `/Library/Spotlight`, PreferencePanes, Screen Savers, Input Methods | Apple lists color pickers, QuickLook and Spotlight (verified) |
| Kexts | `/Library/Extensions` (installed), `kmutil showloaded --list-only` (loaded) | [Eclectic Light](https://eclecticlight.co/2024/12/03/managing-kernel-extensions/). CLI reported. |
| System / network / endpoint extensions | `systemextensionsctl list` (grouped by network, endpoint security, driver, camera, with team ID, bundle ID, version and state) | reported ([krypted](https://krypted.com/mac-security/macos-script-to-list-system-extensions-and-their-state/)) |
| Login items / launchd | Read plists in `/Library/LaunchAgents`, `/Library/LaunchDaemons`, `~/Library/LaunchAgents`, resolve `ProgramArguments[0]`, then check its architecture. `SMAppService` only reports on your own app's helpers. | The full Background Task Management list needs root (`sfltool dumpbtm`, unverified). |
| CLI tools | Intel Homebrew prefix `/usr/local`, Apple silicon prefix `/opt/homebrew`, MacPorts `/opt/local` | Rosetta Check already does this |
| Vendor-certification status | **Map bundle ID and team ID to a curated JSON of vendor statements for the target OS.** Host it as a static file on GitHub or a CDN and fetch it at runtime. | **This is the real gap and a recurring manual curation job.** Scraping RoaringApps is not viable (no public API, unverified). |

### 4b. Constraints
- **Sandbox / Mac App Store.** Rosetta Check does all of this sandboxed, asking for read-only access to user folders, so it is feasible. For a lifetime licence sold outside the App Store, a Developer ID notarized build avoids sandbox friction. Anything that needs root (BTM, some `/Library` data) needs a privileged helper or can simply be skipped.
- **macOS 27 blocks direct TCC.db access.** Do not design features that read privacy permissions from the database (verified via Apple enterprise notes).
- **Undocumented `system_profiler` formats change between releases.** Jamf had to patch its script for Golden Gate.
- **Hardware-coupled failures** (dock or audio-interface drivers) cannot be proven from inventory alone. At best the app can flag "vendor says not supported".

### 4c. What an app can do that competitors don't (the gap for need 2)
1. **Baseline snapshot and diff.** Before upgrading, record apps, versions, architectures, plug-ins, AU validation results, printers, extensions, login items, VPN profiles, Rosetta installed yes/no, and "Open using Rosetta" flags. After upgrading, re-scan and show a diff: "Rosetta was removed. These 4 items need it. [Reinstall Rosetta]"; "12 AUs failed `auval`"; "Printer X lost its PDE"; "Open using Rosetta was reset for Photoshop, so Intel-only plug-in Y won't load". Every one of these is a documented macOS 27 behaviour.
2. **A "my workflow" checklist.** The user picks the 3–10 things they must be able to do. The app suggests tests based on the inventory (a DAW session, a print, a VPN connection, an export) and keeps pass/fail results before and after the upgrade.
3. **Vendor-status mapping** for installed items, with a "last checked" date and a link to the vendor page.
4. **Go / no-go verdict plus rollback readiness.** Confirm there is a recent Time Machine backup or bootable clone (CCC 7 supports 27) before saying "go".

## 5. Is "test drive the new macOS in a VM with your project files" realistic for a solo developer?

### What is technically available (verified in Apple docs)
- Core classes: `VZMacOSRestoreImage` (with `fetchLatestSupported(completionHandler:)`, `mostFeaturefulSupportedConfiguration`), `VZMacOSInstaller`, `VZMacPlatformConfiguration`, `VZMacHardwareModel`, `VZMacAuxiliaryStorage`, `VZMacMachineIdentifier`, `VZMacOSBootLoader`, `VZMacGraphicsDeviceConfiguration`, `VZVirtioBlockDeviceConfiguration`, and `VZVirtualMachineView`. All macOS 12+ ([Apple sample](https://developer.apple.com/documentation/virtualization/running-macos-in-a-virtual-machine-on-apple-silicon)).
- Shared project folders: `VZVirtioFileSystemDeviceConfiguration` with `macOSGuestAutomountTag` (macOS 13+). A read-only share protects the originals.
- Save/restore state: `saveMachineStateTo(url:completionHandler:)` (macOS 14+).
- **New in macOS 27:** `VZMacGuestProvisioningOptions` (`fullName`, `username`, `password`, `logsInAutomatically`, `enablesRemoteLogin`), passed through `VZMacOSVirtualMachineStartOptions`. Apple: "requires guest macOS 27 or later… macOS only evaluates these options on the first boot after restore." **This skips Setup Assistant, but only when the host itself runs macOS 27** (introduced in 27.0). **It is useless for the main use case, a user still on 26 who wants to preview 27.** Also new: `DiskImageKit` for ASIF and stacked base images (macOS 27).
- Entitlement: `com.apple.security.virtualization` ([Apple docs](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.virtualization)). It is allowed in the Mac App Store, since CleanRoom and UTM ship there.
- iCloud inside VMs works only for macOS 15+ VMs created from a 15+ image. It is tied to the host's Secure Enclave, and moving the VM to another Mac requires signing in again ([Apple docs](https://developer.apple.com/documentation/virtualization/using-icloud-with-macos-virtual-machines)).

### Blocking or expensive problems
1. **Host/guest version fragility.** An Apple engineer wrote: "A macOS 27 guest should run on a macOS 26.6 host, but we discovered a late incompatibility between the `VZMacOSInstaller` API on macOS 26.6 and the macOS 27 IPSW." DTS says the OS-level fix (r. 179068335) is in macOS 26.6b3 (25G5052e), and that Xcode 27's MobileDevice package makes it worse ([Apple forums 830118](https://developer.apple.com/forums/thread/830118), [motionbug](https://motionbug.com/virtualising-macos-27/), [OSXDaily](https://osxdaily.com/2026/06/12/macos-golden-gate-27-beta-wont-install-in-a-virtual-machine-its-a-known-issue/)). Workarounds: install a 26 guest and then do an OTA upgrade inside it, or use InstallAssistant.pkg. **You would re-live this every year, and the target user is exactly someone on the older host.**
2. **The license and framework cap of 2 concurrent macOS VMs.** The third VM fails with VZErrorDomain code 6 ([Eclectic Light](https://eclecticlight.co/2022/08/04/virtualisation-on-apple-silicon-macs-8-how-apple-limits-vms/)). The EULA allows "up to two (2) additional copies… for… (a) software development; (b) testing during software development; (c) using macOS Server; or (d) personal, non-commercial use". **A consumer testing their own work fits (d). A professional's commercial workflow testing is a grey area** (legal review needed, unverified).
3. **The user's real environment doesn't transfer.** Apps have to be reinstalled in the guest. App Store sign-in "may fail" (Parallels KB). Licence activations (iLok, Native Access, Adobe) count against per-machine limits (unverified per vendor). There is no audio-interface or iPhone passthrough. USB passthrough needs both host and guest on macOS 27. GPU is paravirtualized, so graphics and audio performance tests say little. Kexts in a VM need reduced security (see the [community gist](https://gist.github.com/steven-michaud/fda019a4ae2df3a9295409053a53a65c)).
4. **Resources.** The IPSW download plus a VM disk is tens of GB (exact macOS 27 IPSW size unverified), and the guest needs several GB of RAM. That is painful on 8 GB / 256 GB Macs, which are the typical non-technical user's machines.
5. **Cannot be tested in your CI.** GitHub's arm64 macOS runners are M1 machines, and GitHub states "Nested-virtualization is not supported due to the limitation of Apple's Virtualization Framework" ([GitHub docs](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)). CI can compile it, but only a physical Apple silicon Mac can run it. **For a developer on Windows with no Mac, this is a hard stop.**
6. **Competition already provides the shell** for $0–$9.99 (VirtualBuddy, UTM, CleanRoom). Tart's FSL licence rules out bundling it in a competing paid product.

### Verdict
- **v1: do not build it.** Instead, ship on-host rehearsal: inventory, vendor status, baseline, workflow checklist and post-upgrade diff.
- **v2 (optional, after you own a Mac):** a thin "Try it in a VM" helper that uses Virtualization.framework directly (the Apple sample is a few hundred lines). Limit it to hosts on macOS 27+ upgrading to 28, so it can use `VZMacGuestProvisioningOptions`. Scope it to **document and plug-in smoke tests without hardware**: auto-share the project folder read-only, run `auval`, open files. Market it for the macOS 28 Rosetta cliff, when most buyers will already be on 27.
- A cheaper alternative: a guided recipe that hands off to VirtualBuddy or UTM, with a checklist of what to test inside the VM.

## 7. Recommendations
1. Do not ship a Rosetta or Intel-binary scanner on its own. It is commoditized: Apple's free Settings list, Rosetta Check at $6.99 and Go64 for free. Include the scan as table stakes and reuse the verified APIs (`Bundle.executableArchitectures`, `NSMetadataQuery` on `kMDItemExecutableArchitectures`, Mach-O header parsing of nested binaries).
2. Build the wedge around upgrade **rehearsal and verification**. Take a pre-upgrade baseline (apps, plug-ins, AU `auval` results, printers and filters, system extensions, kexts, launchd items, Rosetta installed yes/no, "Open using Rosetta" flags). After the upgrade, re-scan, diff and offer one-click fixes such as reinstalling Rosetta with `softwareupdate --install-rosetta --agree-to-license`. Each of these maps to a behaviour Apple documented in the macOS 27 release notes (163213094, 168097174, 176042635).
3. Add a curated vendor-certification feed: a JSON keyed by bundle ID and team ID, holding vendor, status for the target OS, source URL and date checked, hosted as a static file. Seed it with high-risk categories: audio (NI, UA, Waves, u-he, Focusrite, MOTU), Adobe, VPN and security, printer and scanner utilities, display and dock drivers. Budget recurring curation time around each WWDC and each September release.
4. Add a "my workflow" checklist. The user picks critical tasks, the app suggests tests from the inventory, and pass/fail is recorded before and after the upgrade. This is the non-technical translation of the enterprise "pilot group".
5. Gate the verdict on rollback readiness (a recent Time Machine backup or bootable clone) and show a plain-English go / wait / no-go.
6. Time the marketing for the macOS 28 Rosetta cliff (WWDC June 2027 to fall 2027), when Intel-only software stops running entirely. Position against subscriptions (Parallels, Bushel), because at least one Bushel reviewer asks for a lifetime option.
7. Defer the VM "test drive" feature. If you build it later, use Virtualization.framework directly: do not embed Tart (FSL Competing Use clause), limit it to macOS 27+ hosts so you can use `VZMacGuestProvisioningOptions`, share project folders read-only through VirtioFS, and scope it to document and plug-in smoke tests without hardware. Buy or rent a physical Apple silicon Mac first, because GitHub arm64 runners cannot nested-virtualize.
8. Prefer Developer ID (notarized, direct-sale) distribution for the lifetime licence and deeper `/Library` scanning. Avoid reading TCC.db (blocked in macOS 27) and treat `system_profiler SPLegacySoftwareDataType` parsing as best-effort.
