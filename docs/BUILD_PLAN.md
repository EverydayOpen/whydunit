## 2. Rules that ship in v1 (Core classifier, `docs/DECISIONS.md` §2.2 numbering)

Implemented: I1 storageFull, I2 serverUnreachable, I4 uploadRejected, I5 lockFlags (copy-command only),
I6 tooLarge, I7 excludedByDesign (info), I8 conflicts (show in Finder), I10 stuckItems, I11 syncStalled,
I13 storageDebt ("at least"), I14 developerFolders, I15 relocatedFiles, I16 onlyOnThisMac,
plus `unreadableFolders` (unknown) and `permissionDenied`.

Not in v1: I3, I9, I12, I17 (help text only), L4, L5, L6(a), L7.

Key semantics:
- **I16 onlyOnThisMac:** items with `isUploaded != true` and not dataless and not excluded. Severity `.warning`
  if any such item has waited (later of `modified` and `inPlaceSince`) longer than `stuckAge`, else `.info`. Title "N items (X) exist only on this Mac". Steps say:
  don't sign out, turn off iCloud Drive or reset anything; back up first. primaryAction `.backUp`.
- **I10 stuckItems:** `isUploaded == false` (explicit), `isUploading != true`, no uploading error, no unresolved
  conflicts, waiting (later of `modified` and `inPlaceSince`) longer than `stuckAge`, probe is `.uploaded`.
  primaryAction `.retryUpload`.
- **I11 syncStalled:** only when probe is `.notUploaded` (explicit false for the whole wait) and no scanned file is
  uploading (then iCloud is busy, not stalled). Never on `.unknown`.
  Severity `.critical`. primaryAction `.restartSync`. Explanation says not to touch individual files yet.
- **nil is unknown, never OK.** Items whose `isUploaded == nil` count toward `Diagnosis.unknownCount`.
- **I13 storageDebt:** Σ logicalSize of dataless items > freeBytes → `.warning`, "at least" wording when any size is nil.
- **I5 lockFlags:** command `chflags nouchg,nouappnd '<path>'` for user flags; prefix `sudo ` when schg/sappnd
  present. Shell-quote paths with single quotes (escape `'` as `'\''`). The app never runs it.

## 3. Hard safety rules (enforced by review and by a CI grep)

- Never call `removeItem`, `unlink`, `rmdir` or `rm` anywhere in `Sources/` or `App/`. Deleting = `FileManager.trashItem`.
- Never read file contents during a scan. Materialization is disabled process-wide at launch:
  `setiopolicy_np(IOPOL_TYPE_VFS_MATERIALIZE_DATALESS_FILES, IOPOL_SCOPE_PROCESS, IOPOL_MATERIALIZE_DATALESS_FILES_OFF)`.
  `EDEADLK` means "dataless" (record it, don't retry).
- Never run a shell (`/bin/sh -c`, `bash -c`). `Process` only with an absolute executable path and an argument array.
- Never toggle iCloud settings, sign out, evict, set `isExcludedFromSync`, kill root-owned processes, touch
  `~/Library/Application Support/CloudDocs`, `FileProvider` or CloudKit caches, write private xattrs, or change permissions.
- Retry Upload (move-out/move-back) requires a **verified** backup entry for that exact item first, runs one item at
  a time, re-checks the item right before acting (skip if modified/size changed since the scan: "Changed since you
  reviewed it"), uses a staging folder on the same volume (`~/Whydunit Backups/.staging/`), and always moves the item
  back even on timeout. Prefer it only for items with `isUploaded == false`.
- Restart iCloud Sync only after an explicit consent sheet; only `/usr/bin/pkill -TERM -x -U <uid> bird`; never loops.
- The backup refuses destinations inside `~/Library/Mobile Documents` or inside an iCloud-synced Desktop/Documents.
  Preflight: free space ≥ 2× copy size; every item must be local (not dataless). Abort on any hash mismatch.
- Every change is appended to the activity log (`AuditEntry`).

## 4. WhydunitMac API contract (implement exactly these public names)

```swift
// Platform/Materialization.swift
public enum Materialization { @discardableResult public static func disableForProcess() -> Bool }

// Platform/SystemInfo.swift
public enum SystemInfo {
    public static func osVersion() -> OSVersion
    public static func freeBytes(at url: URL) -> Int64?          // volumeAvailableCapacityForImportantUsageKey
    public static var homeDirectory: URL { get }                 // real home (FileManager.homeDirectoryForCurrentUser)
}

// Platform/ProcessRunner.swift
public struct ProcessResult: Sendable { public let status: Int32; public let stdout: String; public let stderr: String; public let timedOut: Bool }
public enum ProcessRunner {
    /// Absolute executable path + args; drains stdout/stderr concurrently (no 64 KB pipe deadlock);
    /// terminates on timeout; caps captured output at `maxOutputBytes`.
    public static func run(_ executable: String, _ arguments: [String], timeout: TimeInterval = 30, maxOutputBytes: Int = 4 << 20) async throws -> ProcessResult
}

// Platform/FinderBridge.swift
@MainActor public enum FinderBridge {
    public static func reveal(_ paths: [String])
    public static func openICloudSettings()      // x-apple.systempreferences:com.apple.systempreferences.AppleIDSettings*iCloud (verify; fall back to opening System Settings)
    public static func openPrivacySettings()     // x-apple.systempreferences:com.apple.preference.security?Privacy_FilesAndFolders
}

// ICloud/ICloudLocations.swift
public struct ICloudLocations: Sendable {
    public let cloudDocs: URL?                   // ~/Library/Mobile Documents/com~apple~CloudDocs if it exists
    public let roots: [ScanRoot: URL]            // iCloudDrive always when cloudDocs exists; desktop/documents only when ubiquitous
    public let relocatedFolders: [String]        // existing "iCloud Drive (Archive)*", "/Users/Shared/Relocated Items"; the classifier adds a second Mac's "Desktop - <Mac>" / "Documents - <Mac>" folders inside iCloud Drive's Desktop/Documents
    public static func current() -> ICloudLocations
    public func contains(_ url: URL) -> Bool     // true if url is inside any iCloud-synced root (used to refuse backup destinations)
}

// ICloud/ICloudScanner.swift
public struct ScanProgress: Sendable { public var phase: String; public var itemsSeen: Int; public var fraction: Double? }
public struct ScanOutput: Sendable { public var items: [ItemRecord]; public var deniedRoots: [ScanRoot] }
public final class ICloudScanner: Sendable {
    public init()
    /// Enumerates each root (skipsPackageDescendants, NOT skipsHiddenFiles), errorHandler returns true
    /// (records listingFailed folders), reads URLResourceValues (removeAllCachedResourceValues first) + lstat st_flags.
    /// Counts descendants (cap 10_000) only for folders named node_modules/.git/.build/Pods/DerivedData.
    /// Cooperative cancellation via Task.checkCancellation(). Progress callback at most ~10×/s.
    public func scan(roots: [ScanRoot: URL], progress: @escaping @Sendable (ScanProgress) -> Void) async throws -> ScanOutput
    /// Re-reads one item (used right before acting and while waiting for upload).
    public func record(at url: URL, root: ScanRoot, rootURL: URL) -> ItemRecord?
}

// ICloud/UploadProbe.swift
public enum UploadProbe {
    /// Writes 1 MB of random bytes to "<cloudDocs>/Whydunit Probe/probe-<uuid>.bin", polls isUploaded every 5 s
    /// up to `timeout`, then trashes the probe (and the folder if empty). Any nil, or an upload error at the end → .unknown.
    public static func run(cloudDocs: URL, timeout: TimeInterval = 120) async -> ProbeResult
}

// Actions/BackupService.swift
public struct BackupProgress: Sendable { public var completed: Int; public var total: Int; public var currentName: String }
public enum BackupError: Error, LocalizedError { case destinationInsideICloud, notEnoughSpace(needed: Int64, available: Int64?), itemNotLocal(String), hashMismatch(String), nothingToBackUp }
public struct BackupService: Sendable {
    public init(backupsRoot: URL, locations: ICloudLocations)
    public static var defaultRoot: URL { get }                               // ~/Whydunit Backups
    /// Copies with NSFileCoordinator(.withoutChanges) reads, preserving relative folders
    /// (<backup>/<root displayName>/<relativePath>), streams SHA-256 (CryptoKit) of source and copy,
    /// writes manifest.json, throws on mismatch (leaving already-verified copies in place).
    public func backUp(_ items: [ItemRecord], now: Date, progress: @escaping @Sendable (BackupProgress) -> Void) async throws -> BackupManifest
    public func listBackups() -> [BackupManifest]                            // reads */manifest.json, newest first
    public func trashBackup(_ manifest: BackupManifest) throws               // FileManager.trashItem
}

// Actions/UploadRetrier.swift
public enum RetryOutcome: Sendable, Equatable { case uploaded(seconds: Double), stillWaiting, skipped(reason: String), failed(reason: String) }
public struct UploadRetrier: Sendable {
    public init(scanner: ICloudScanner, stagingRoot: URL)
    /// Move-out/move-back for ONE item. Preconditions checked inside: not a plain folder, verified backup entry for
    /// item.path whose copy is still there, item unchanged since scan (size + modified), not dataless,
    /// isUploaded == false, hash matches the backup. Always attempts to move the item back.
    public func retry(_ item: ItemRecord, rootURL: URL, backup: BackupManifest.Entry, waitAfterReturn: TimeInterval = 120) async -> RetryOutcome
    /// Puts back items a quit or crash left in staging (original path from <uuid>/.whydunit-original-path, or
    /// "… (Whydunit restored)" if taken). Call at launch before any retry. Returns where each item now is.
    public static func recoverStaged(in stagingRoot: URL) -> [String]
}

// Actions/SyncService.swift
public enum SyncService {
    /// Runs /usr/bin/pkill -TERM -x -U <getuid()> bird. Returns true if a process was signalled.
    public static func restartBird() async throws -> Bool
}

// Store/ActivityLog.swift
public actor ActivityLog {
    public init(url: URL)
    public static var defaultURL: URL { get }                                // App Support/Whydunit/activity.jsonl
    public func append(_ entry: AuditEntry)
    public func all() -> [AuditEntry]                                        // newest first; skips bad lines
}
```

## 5. App target contract (`App/`)

`AppStore` is the single `@Observable @MainActor final class` source of truth, created in `AppDelegate`
(`let store = AppStore()`) and passed to scenes with `.environment(appDelegate.store)`.

```swift
enum Route: Hashable { case summary, finding(RuleID), backups, activity }
enum ScanState: Equatable { case never, scanning(phase: String, itemsSeen: Int, fraction: Double?), done, failed(String) }
enum ActiveSheet: Identifiable { case backUp(paths: [String], thenRetry: [String]? = nil), retryUpload(paths: [String]), restartSync; var id: String }

@Observable @MainActor final class AppStore {
    var route: Route? = .summary
    var scanState: ScanState = .never
    var diagnosis: Diagnosis?
    var itemsByPath: [String: ItemRecord] = [:]
    var probe: ProbeResult = .notRun
    var locations: ICloudLocations
    var selection: Set<String> = []            // item paths selected in the current finding's table
    var inspectorShown = false
    var sheet: ActiveSheet?
    var backups: [BackupManifest] = []
    var activity: [AuditEntry] = []
    var backupsRoot: URL                       // UserDefaults "backupsRoot" or BackupService.defaultRoot
    var lastScanDate: Date?
    var stopRequested: Bool                    // set by Stop or Quit; retryUpload checks it between items
    private(set) var isRetrying: Bool
    let recoveredPaths: [String]               // UploadRetrier.recoverStaged at init; AppDelegate reports them
    static let probePhase: String
    static var stagingRoot: URL                // BackupService.defaultRoot/.staging (home volume)

    func scan()                                // cancels a running scan; runs scanner + probe; classifies; refreshes backups/activity
    func cancelScan()
    func finding(_ rule: RuleID) -> Finding?
    func items(for finding: Finding) -> [ItemRecord]
    func request(_ action: FixAction, for finding: Finding, paths: [String])  // Back Up / Retry Upload / Restart iCloud Sync: stops a scan, opens its consent sheet; others run now
    func backUp(paths: [String], progress: @escaping (BackupProgress) -> Void) async throws -> BackupManifest
    func trashBackup(_ m: BackupManifest) async throws                  // logs, refreshes
    func retryUpload(paths: [String], progress: @escaping (String, RetryOutcome?) -> Void) async   // requires verified backups; logs each; stops between items when stopRequested; skips all when probe is .notUploaded
    func restartSync() async -> AuditEntry     // the logged entry: restarted, wasn't running, or failed
    func copyDiagnosis()                       // NSPasteboard, text from Core DiagnosisText
    func exportCSV(for finding: Finding) -> String
}
```

`.windowResizability(.contentMinSize)`, main view min 1000×640; `Settings` with 2 tabs (General, Advanced).
AppDelegate: `NSWindow.allowsAutomaticWindowTabbing = false` in `applicationWillFinishLaunching`,

## 6. UI decisions (override UI_SPEC where different)

Follow UI_SPEC §0 rules, §2 tokens (spacing, typography, severity color/symbol/word, motion), §5 copy tone —
with these changes from the review:
- **No onboarding flow.** The never-scanned state *is* the welcome: app icon, one sentence, one privacy line
  ("Everything stays on this Mac. Whydunit reads file status, never file contents."), a prominent
  **Scan iCloud Drive** button. Permission is asked in context (the scan triggers the macOS prompt;
  EPERM → permission state with "Open Privacy Settings").
- **Sidebar** (`List(selection:)`): Section "iCloud Drive": `Summary` + one row per current finding
  (SeverityIcon, short name, trailing count badge). Section "History": `Backups`, `Activity`.
- **Summary** = `Form { … }.formStyle(.grouped)`: first section is the hero (28 pt SeverityIcon + title =
  headline finding's fact in `.title2.weight(.semibold)` or "No problems found"; one meta line
  "4,213 items checked · 2 need attention · 3 couldn't be checked"); then a "Findings" section with one plain row
  per finding (icon, title, one secondary line; row click navigates to the finding); then an "iCloud Drive" section
  with `LabeledContent` rows: Sync check (probe result), Free on this Mac, Scanned folders.
- **Finding detail** = `VStack(spacing: 0) { header; Table }`. Header: icon + title, explanation, numbered steps,
  action buttons (at most one `.borderedProminent`, only the finding's primary action; others `.bordered`).
  `Table(items, selection: $store.selection, sortOrder:)` columns: Name (middle truncation, file icon via
  NSWorkspace), Folder, Size ("At least" when partial), Status (plain words: "Waiting to upload", "Upload failed",
  "Only in iCloud", "Not synced by design", "Unknown"), Modified. Pre-select safe rows (not modified in the last
  10 minutes, not dataless) only on findings whose primary action is Back Up or Retry Upload. No checkbox column. Findings without items show no table.
- **Toolbar:** plain `arrow.clockwise` Scan button; while scanning a small circular `ProgressView` + Stop button.
  `.navigationSubtitle` = phase text while scanning, "Scanned 2 min ago" otherwise, "3 selected · 1.1 GB" when a
  table selection exists. Contextual primary toolbar button only on finding pages with a selection
  ("Back Up…" / "Retry Upload…"). Inspector toggle (`sidebar.trailing`).
- **First scan:** centred determinate/indeterminate `ProgressView` + phase label (no skeletons). Rescans keep old
  results visible.
- **Inspector:** "Technical details" of the selected item (all raw ItemRecord values, monospaced, selectable;
  errors with domain/code). Empty → `ContentUnavailableView("No Selection", systemImage: "sidebar.trailing")`.
- **Sheets:** BackUpSheet (review → running → done; Return starts because nothing destructive happens),
  RetryUploadSheet (review with the cross-device warning → running per item → per-item outcomes), RestartSyncSheet
  (consent). No arm delays needed because no action deletes anything; Cancel is `.cancelAction`.
- **Settings**: General (Automatically check for updates — Sparkle binding; Backups folder with Choose…),
  Advanced (Open Activity Log folder, Reset Whydunit… which clears settings; never touches backups).
- Colors: system colors only; `.info` renders `.secondary` (not blue, it clashes with the accent). No custom glass.
  No card backgrounds on content. No confetti. No pulsing.
- Accessibility: every icon-only button has a label/help; severity always has its word for VoiceOver;
  respect Reduce Motion via `Motion` token.
